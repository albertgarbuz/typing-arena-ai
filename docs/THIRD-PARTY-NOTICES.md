# Сторонние компоненты и шрифты

Проект использует библиотеки из package.json/pnpm-lock.yaml. Их исходные лицензии поставляются с npm-пакетами; перед изменением способа распространения необходимо соблюдать условия каждой зависимости.

## Локально размещённые шрифты

- **Manrope** — пакет @fontsource/manrope, лицензия SIL Open Font License. Полный текст поставляется в `apps/web/public/licenses/Manrope-OFL.txt` и доступен на сайте по `/licenses/Manrope-OFL.txt`.
- **JetBrains Mono** — пакет @fontsource/jetbrains-mono, лицензия SIL Open Font License. Полный текст: `apps/web/public/licenses/JetBrains-Mono-OFL.txt`, URL `/licenses/JetBrains-Mono-OFL.txt`.

Шрифты не запрашиваются у Google Fonts или сторонних CDN при посещении сайта. Иконки и иллюстрации текущего этапа созданы в коде проекта, без копирования чужих логотипов или графических материалов.
