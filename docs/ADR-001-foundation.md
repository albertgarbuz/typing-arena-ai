# ADR-001: основа первого этапа

Дата: 2026-10-11. Статус: принято пользователем; реализация этапа 1.

## Решение

Один pnpm workspace; Next.js App Router / React / TypeScript; Tailwind CSS 4 с собственными CSS-токенами. Текущий единственный workspace — `apps/web`. Общие пакеты, PostgreSQL, авторизация, realtime и AI добавляются по мере соответствующих этапов, а не в виде пустых реализаций сейчас.

Node.js 24 LTS и pnpm установлены в пользовательскую папку Pipali, без глобальных изменений. `.node-version`, packageManager и lockfile фиксируют среду. Скрипт `scripts/run.sh` умеет использовать эту среду; на другом компьютере достаточно стандартного Node.js 24 и pnpm 10.34.6.

## Границы этапа

Реальные функции: главная, страницы `/methodology` и `/roadmap`, ссылка на содержимое, мобильное меню, RU/EN-переключатель иллюстрации, светлая/тёмная темы с сохранением, страница 404. Никаких пользователей, тренировок, записей БД, AI-ответов или live-соперников не имитируем.

Переключатель RU/EN меняет описание курса, а не переводит весь сайт и не создаёт учебный прогресс. Клавиатура и дорожки арены обозначены как иллюстрации. Формулы на странице методики — спецификация будущего расчётного движка, не доказательство реализации тренажёра.

## Тема

Тёмная по умолчанию. Явный выбор сохраняется в localStorage под `typing-arena-theme`. Короткий статический script задаёт тему до первого рендера; состояние React синхронизируется через `useSyncExternalStore`. При недоступном хранилище тема остаётся рабочей до перезагрузки. Событие storage синхронизирует вкладки.

## Безопасность первого этапа

Нет auth, ввода секретов и API, изменяющих данные. Заголовки nosniff, DENY, referrer policy, ограничение доступа к камере/микрофону/геолокации и базовый CSP. Это не полная CSP-политика будущего приложения: nonce/script policy, CSRF, сессии, роли и 2FA проверяются в соответствующих этапах. Нет внешних аналитических скриптов и CDN-шрифтов: шрифты размещаются локально из Fontsource с лицензиями в зависимостях. Индексация поисковиками отключена для незавершённой версии.

## Проверки

Unit: нормализация темы, переключение, исполнение pre-paint script, закрытое хранилище.
Browser: Chromium и WebKit; темы, вкладки курса, меню, ссылки/якоря, размеры 360/768/1280/1440, reduced motion, skip-link, axe WCAG A/AA, 404 и заголовки.

Точный выполненный результат и ограничения — в `STAGE-1-REPORT.md`, а не в этом решении. Построение и E2E-тесты запускаются на production-сборке.
