# Typing Arena AI — отчёт по этапу 1

**Дата:** 11 октября 2026. **Статус:** реализован, автоматические проверки пройдены, готов к проверке владельцем. Этап 2 не начат.

## Что создано

- Настоящий проект Next.js 16.4.0, React 19.3.0, TypeScript 5.9.3, Tailwind CSS 4.3.3; Node.js 24.21.0 LTS, pnpm 10.34.6, закреплённые зависимости и lockfile.
- Главная страница с заданным заголовком, оригинальной клавиатурной иллюстрацией, обзором обучения, AI, арены и метрик.
- Рабочая навигация, мобильное меню с Escape и возвратом фокуса, ссылки на реальные страницы.
- Тёмная и светлая темы: сохранение, начальная установка до React, поддержка закрытого хранилища и синхронизация через storage events.
- Реальный переключатель RU/EN для обзора двух независимых курсов; управление стрелками/Home/End.
- Страницы `/methodology`, `/roadmap`, отдельная 404.
- Локальные шрифты с кириллицей и копии OFL-лицензий; нет внешней аналитики или CDN-запросов шрифтов.
- Стартовый `.command`-файл для Mac, README, исходный согласованный план, архитектурное решение и тесты.

## Что НЕ реализовано

Регистрация, сессии и Google OAuth, PostgreSQL, тренажёр с измерением ввода, сохранение результатов, AI API, живые матчи, рейтинг, турниры, XP, друзья и административный доступ. Они относятся к следующим этапам. Клавиатура/дорожки подписаны как иллюстрации. Сайт не опубликован в интернете.

### Браузерные сценарии

Точный заголовок; CTA-якоря; сохранение темы после refresh и перехода страницы; тема при недоступном localStorage; RU/EN и keyboard tabs; мобильное меню; возврат из методики на раздел главной; skip-link; reduced motion; отсутствие горизонтального переполнения; axe в двух темах; рабочие URL и якоря; честная 404 и серверные заголовки.

В Safari/WebKit на macOS для перехода по ссылкам использована штатная **Option+Tab**, если полная клавиатурная навигация не включена в системе. Это проверено отдельным экспериментом: обычный Tab переходил к вкладке курса, Option+Tab — к skip-link. Тест не подменяет клавиатурную навигацию программной установкой фокуса.

- Устранено замечание линтера к анонимному default export конфигурации PostCSS.
- Явный ESM-режим устранил предупреждение загрузки Vitest-конфигурации.
- Исправлены переходы header-якорей с внутренних страниц на главную.
- Убран дублирующий skip-link; мобильная кнопка меняет доступное имя при открытии.
- Уточнено содержание: десять уровней соответствуют ТЗ, RU/EN независимы, гонка идёт по времени, нет абсолютных обещаний античита, AI не определяет реально использованные пальцы.
- Формулировка точности различает попытки ввода и символы конечного текста.
- Учтён штатный режим клавиатурной навигации WebKit/macOS. После исправлений полный набор проверок повторён успешно.

## Ограничения проверки

- WebKit — движок Safari в Playwright, не физический iPhone и не все версии установленного Safari. Firefox и реальные мобильные устройства отдельно не проверялись.
- Axe не заменяет ручной аудит WCAG, проверки screen reader и исследования с пользователями.
- Нет нагрузочного теста, проверки БД или OpenAI: соответствующие функции ещё не создавались.
- Lighthouse/Core Web Vitals не измерялись; оценка производительности числом не заявляется.
- `pnpm audit` не является полной проверкой безопасности, а нулевой список известных уязвимостей не доказывает их отсутствие вообще.
- Базовый CSP текущего информационного сайта не заменяет будущую политику для авторизации и данных.
- Полноценное production-развёртывание и интернет-домен отсутствуют. Локальный сервер слушает только 127.0.0.1.

## Проверка владельцем

1. Открыть `http://127.0.0.1:3000`, пока локальный сервер запущен.
2. Переключить тему в правом верхнем углу; обновить страницу.
3. Нажать «Посмотреть программу», переключить RU/EN.
4. Открыть «Методика расчёта» и «Статус разработки» внизу страницы.
5. Сузить окно до мобильной ширины и проверить меню.
6. Оценить оформление и понятность текста. После подтверждения перейти к этапу 2.

Повторный запуск — `Start Typing Arena.command` либо `./scripts/run.sh dev`. Терминал/фоновый процесс должен продолжать работать, иначе локальный адрес недоступен.
