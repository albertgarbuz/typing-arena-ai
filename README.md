# Typing Arena AI

Первый этап настоящей веб-платформы обучения слепой печати и соревнований.

**Текущий объём:** главная, дизайн-система, навигация, две темы, обзор RU/EN-программ, методика и план разработки. Регистрация, база данных, тренажёр, AI и гонки пока не реализованы. Иллюстрации не выдаются за работающие функции.

## Открыть на этом Mac

Если сайт уже запущен: **http://127.0.0.1:3000**.

Для повторного запуска дважды нажмите `Start Typing Arena.command` в этой папке. Откроется окно Terminal и браузер. Оставьте Terminal открытым; Control+C остановит сервер. Если macOS запросит разрешение открыть файл, используйте контекстное меню → «Открыть».

Через Terminal:

```bash
cd /Users/mac/Projects/typing-arena-ai
./scripts/run.sh dev
```

Для производственного локального режима:

```bash
./scripts/run.sh build
./scripts/run.sh start
```

Одновременно запускается один сервер на порту 3000. `127.0.0.1` доступен только с этого компьютера: сайт не опубликован в интернете и не открыт в локальную сеть.

## Другой компьютер / чистая установка

1. Установите Node.js 24 LTS и pnpm 10.34.6.
2. Откройте папку проекта в Terminal.
3. Выполните:

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm dev
```

В первом этапе переменные окружения и секреты не нужны. Есть `.env.example` с пояснениями. `.env` и производные игнорируются Git; секреты запрещено размещать в `NEXT_PUBLIC_*`.

На исходном Mac изолированные инструменты находятся в `~/.pipali/runtimes/`; `scripts/run.sh` подхватывает их автоматически. Глобальные Node/npm или настройки macOS не менялись.

## Проверки

```bash
./scripts/run.sh lint
./scripts/run.sh typecheck
./scripts/run.sh test
./scripts/run.sh build
./scripts/run.sh test:e2e
```

Для E2E на другом компьютере предварительно установите браузеры:

```bash
pnpm --filter @typing-arena/web exec playwright install chromium webkit
```

E2E сами запускают production-сервер, если на порту 3000 нет уже запущенной версии. Перед проверкой нужно собрать проект. Локальные тестовые браузеры на исходном Mac находятся в `~/.pipali/browsers`. WebKit — тест движка Safari, а не полный прогон в установленном приложении Safari на всех устройствах.

HTML-отчёт браузерных тестов: `apps/web/playwright-report/index.html`.
Фактический итог этапа: [docs/STAGE-1-REPORT.md](docs/STAGE-1-REPORT.md).
